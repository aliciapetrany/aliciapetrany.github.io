Overview

CSHintR is a R wrapper for the CSHint python package, which performs cross species scRNA-seq integration. Note that this implementation will only run on linux based OS.

Example Usage

Installation

These are not the final integration instructions; however, while the CSHint repo is privated, this is how to install the r version.

First, clone the CSHint directory

git clone https://github.com/aliciapetrany/CSHint
cd CSHint/CSHintR

Then, open the R project for the package in R-studio:

rstudio CSHintR.Rproj

In R studio, run the following:

install.packages("devtools")
devtools::install()

If you are running this on a fresh linux install, you will likely be missing many of the linux dependencies that are necessary for this package to compile. Copy and paste the error message into an AI and it will tell you how to install the proper linux binaries.

Before you get started:

CSHint requires the following inputs to run: - Cleaned anndata objects (1 per species) containing raw counts in the .X slot stored in .h5ad format - Reference proteomes (1 per species), in which the header directly corresponds to gene names in the h5ads. For example:

    >gene 1
      <sequence>
    >gene 2
      <sequence

The h5ad files can be generated natively in R from a seurat object with CSHintR’s built-in converter:

seurat_to_h5ad <- function(<seurat object>, <path>)

If you are using proteomes from public NCBI or ENSEMBL assemblies, CSHintR can preprocess them for you. In this case, download both the proteomes and the corresponding GTF or GFF3 files, and CSHint will properly format the proteome fastas in the preprocess module.

Integration

Once the package is installed, you can load it in with the following command:

library(CSHintR)

The integration module directly calls upon the python script with reticulate and wraps the python objects into R6 objects. The package as an embedded yml file denoting the necessary dependencies to run the python modules. The conda environment can be set up with the following commands:

install_CSHint_env() # only needs to be run once
reticulate::use_condaenv("cshint_env", required = TRUE) # needs to be run for every R-session

After this point, the pipeline runs identically to the python one, with R6 syntax and lists instead of dictionaries

Preprocessing

Preprocess FASTA headers

Rename raw proteome FASTA headers to gene symbols using each species’ annotation file (GTF or GFF3, RefSeq or Ensembl — auto-detected):

pre <- CSHintPreprocess$new()

datapath <- "Proteomes/"

path_dict <- list(
  human      = list(gtf = paste0(datapath, "human.gtf"),
                    fasta = paste0(datapath, "human.faa")),
  chicken    = list(gtf = paste0(datapath, "chicken.gtf"),
                    fasta = paste0(datapath, "chicken.faa")),
  opossum    = list(gtf = paste0(datapath, "opossum.gtf"),
                    fasta = paste0(datapath, "opossum.faa")),
  squirrel   = list(gtf = paste0(datapath, "squirrel.gtf"),
                    fasta = paste0(datapath, "squirrel.faa")),
  zebrafish  = list(gtf = paste0(datapath, "zebrafish.gtf"),
                    fasta = paste0(datapath, "zebrafish.faa"))
)

pre$preprocess_fasta_headers(path_dict, out_dir = "filtered_proteomes")

Synchronize scRNA-seq and proteomes

Filter each species’ scRNA-seq and protein sequences down to their shared genes:

path_dict <- list(
  human      = list(h5ad = "cleaned_scrna_h5ads/human_raw.h5ad",
                    fasta = "filtered_proteomes/human.faa"),
  chicken    = list(h5ad = "cleaned_scrna_h5ads/chicken_raw.h5ad",
                    fasta = "filtered_proteomes/chicken.faa"),
  opossum    = list(h5ad = "cleaned_scrna_h5ads/opossum_raw.h5ad",
                    fasta = "filtered_proteomes/opossum.faa"),
  squirrel   = list(h5ad = "cleaned_scrna_h5ads/squirrel_raw.h5ad",
                    fasta = "filtered_proteomes/squirrel.faa"),
  zebrafish  = list(h5ad = "cleaned_scrna_h5ads/zebrafish_raw.h5ad",
                    fasta = "filtered_proteomes/zebrafish.faa")
)

pre$synchronize_scrna_and_proteomes(
  species_map  = path_dict,
  prot_out_dir = "filtered_proteomes/",
  scrna_out_dir = "filtered_scrna/"
)

Run OrthoFinder

CSHint requires Orthofinder’s orthogroup classifications. CSHintR has a build in orthofinder wrapper that outputs the orthofinder results in the same directory as the reference proteomes. In the example below, the orthofinder referenced later in the pipeline would be “filtered_protomes/Orthofinder/Results_/”

ow <- OrthoFinderWrapper$new()

ow$run_orthofinder(
  inputdir = "filtered_proteomes/",
  orthofinder_path = "orthofinder",
  threads = 16
)

Merge scRNA-seq into a joint orthogroup-layer matrix

After obtaining sequence orthology information, the next step is running merginer the cross species count matrix:

scrnadirs <- list(
  human     = "filtered_scrna/human.h5ad",
  chicken   = "filtered_scrna/chicken.h5ad",
  opossum   = "filtered_scrna/opossum.h5ad",
  squirrel  = "filtered_scrna/squirrel.h5ad",
  zebrafish = "filtered_scrna/zebrafish.h5ad"
)

merger <- CSHintMerger$new(
  orthofinder_resultdir = "filtered_proteomes/OrthoFinder/Results_Sep15/",
  scrna_dirs = scrnadirs,
  output_dir = "merged_output/",
  annotation_obs_col = "metacluster"  # column in adata$obs holding cell type annotations
)

merger$run()

Cross-species integration

Once the matrix is merged, integration can be run:

# Run the integration model
analysis <- CSHintIntegration$new("merged_output/", reference_species = "chicken")
analysis$load()

analysis$select_features(
  discriminability_threshold = 0.6,
  conservation_threshold = 0.2
)

adata = analysis$prepare_for_integration()

 analysis$integrate(
  adata,
  n_trials = 10,
  cell_type_agnostic = FALSE,
  min_anchor_weight = 0.4
)

adata = analysis$post_integration_correction(
  adata = adata, 
  group_cols = c("species", "cell_type"),
  pval_cutoff = 10^-10
) #this will automatically save out the adata

After integration

In addition to the integration module, CSHintR provides some downstream plotting functionality

Loading in the CSHint integration object

The results from the CSHint integration module can be loaded back in from the python modules with the following command:

#the orthofinder directory generated by OrthoFinderWrapper
orthofinder.dir <- "filtered_proteomes/OrthoFinder/Results_Sep18/"
#the result directory generated by CSHintIntegration
mergedir <- "merged_output/"

cshintobj <- load.CSHintR.obj(merged.dir = mergedir, orthofinder.dir = orthofinder.dir)
#> Dropping 9953 of 40548 cells absent from the integrated embedding.
#> Warning: Feature names cannot have underscores ('_'), replacing with dashes
#> ('-')

UMAPs

To plot a umap with the integrated embeddings, run the following:

cshintobj <- run_umap(cshintobj)
plot_umap(cshintobj, color = "cell_type")

If you’d only like to plot a subset a cells, you can subset the object, then run the umap again:

sub_cshintobj <- subset_cells(cshintobj, cshintobj$colmetadata$cell_type != "Rods")
#> Keeping 5208 of 30595 cells.
sub_cshintobj <- run_umap(sub_cshintobj)
plot_umap(sub_cshintobj, color = "cell_type")

Tree Heatmaps

If you want to plot the expression of genes wtihin an orthogroup, it can be done with a cluster heatmap. This series of commands clusters genes within an orthogroup using a dynamic tree cut algorithm on the Orthofinder gene trees. Then, it extracts the counts for every gene in an orthogroup.

Note that Orthofinder classifications, while accurate most of the time, are not perfect. If a gene is missclassified (i.e, a name match for a gene in another species is found in another orthogroup), genes from other, related orthogroups will be plotted as well. To disable this, these genes can be filtered out of the heat map dataframe before passing it into plot_cluster_heatmap

OG = cshintobj$orthogroups$Orthogroup[2500] # pick an arbitrary orthogroup for example

#this line is unneccessary, but if you'd just like the get the gene clusters, run this: 
clusters = cluster_genetree(OG = OG, CSHintR.obj = cshintobj)
#>  ..cutHeight not given, setting it to 1.33  ===>  99% of the (truncated) height range in dendro.
#>  ..done.

#to get the plot, run this
heatdf <- get_heatmap_dataframe(OG = OG, CSHintR.obj = cshintobj)
#>  ..cutHeight not given, setting it to 1.33  ===>  99% of the (truncated) height range in dendro.
#>  ..done.
p <- plot_cluster_heatmap(heatdf = heatdf, OG = OG, CSHintR.obj = cshintobj)

#> Adding another scale for y, which will replace the existing scale.

Full Documentation

Setup

install_CSHint_env()

Creates the conda environment the Python classes need, from the environment.yml bundled with the package.

  • envname — name of the conda environment to create. Default "cshint_env".

Returns TRUE, invisibly.

install_CSHint_env()

# point reticulate at it before creating any wrapper object
reticulate::use_condaenv("cshint_env", required = TRUE)

Reticulate binds to an interpreter the first time Python is touched and will not switch afterwards, so use_condaenv() must come before any $new() call below.

Python wrappers

OrthoFinderWrapper

Runs OrthoFinder and reads its output.

ofw <- OrthoFinderWrapper$new()

$run_orthofinder(inputdir, orthofinder_path, threads = 16L)

Runs OrthoFinder over a directory of proteome FASTA files. Blocks until it finishes; results are written beneath inputdir, not returned.

  • inputdir — directory of proteome FASTA files to compare.
  • orthofinder_path — path to the OrthoFinder executable.
  • threads — threads for OrthoFinder to use. Default 16.

$read_orthogroups(orthofinder_dir)

Reads Orthogroups.tsv from a completed run into a data frame.

  • orthofinder_dir — OrthoFinder output directory (the one containing an Orthogroups/ subdirectory).
ofw$run_orthofinder(
  inputdir         = "filtered_proteomes/",
  orthofinder_path = "~/bin/orthofinder",
  threads          = 16
)

ogs <- ofw$read_orthogroups("filtered_proteomes/OrthoFinder/Results_Sep15/")

CSHintPreprocess

Prepares FASTAs and scRNA-seq data so the two agree on gene names.

prep <- CSHintPreprocess$new()

$preprocess_fasta_headers(gtf_fasta_map, out_dir)

Renames FASTA headers from raw accessions to gene symbols. Detects RefSeq vs Ensembl (and GTF vs GFF3) per species. Writes a renamed {species}.faa and a {species}_id_map.csv for each species.

  • gtf_fasta_map — named list, one entry per species, each an inner named list with gtf and fasta paths.
  • out_dir — destination for the renamed FASTAs and ID maps. Required.

$synchronize_scrna_and_proteomes(species_map, prot_out_dir, scrna_out_dir)

Filters scRNA-seq and protein sequences down to shared genes. Headers are assumed to already be gene symbols; both sides are upper-cased before intersecting, so they need only agree up to case. Species with no shared genes are skipped with a warning.

  • species_map — named list, one entry per species, each an inner named list with h5ad and fasta paths.
  • prot_out_dir — directory for the filtered proteomes. Required.
  • scrna_out_dir — directory for the filtered expression data. Required.
prep$preprocess_fasta_headers(
  gtf_fasta_map = list(
    chicken = list(gtf = "chicken.gtf", fasta = "chicken.faa"),
    human   = list(gtf = "human.gtf",   fasta = "human.faa")
  ),
  out_dir = "renamed_proteomes/"
)

prep$synchronize_scrna_and_proteomes(
  species_map = list(
    chicken = list(h5ad = "chicken.h5ad", fasta = "renamed_proteomes/chicken.faa"),
    human   = list(h5ad = "human.h5ad",   fasta = "renamed_proteomes/human.faa")
  ),
  prot_out_dir  = "filtered_proteomes/",
  scrna_out_dir = "filtered_scrna/"
)

CSHintMerger

Merges per-species scRNA-seq into a joint orthogroup-layer matrix. All configuration happens at construction; $run() executes the pipeline.

$new(...)

  • orthofinder_resultdir — OrthoFinder results used for orthogroup assignment.
  • scrna_dirs — named list of scRNA-seq paths keyed by species. The names define the species set for the run.
  • output_dir — destination for the merged matrix and metadata.
  • annotation_obs_col — column in adata.obs holding cell type labels.
  • ncores — worker processes for parallelised steps. Default 16.
  • counts_layer — layer holding raw counts, e.g. "counts". NULL uses adata$X. Set this whenever adata$X was normalised in place.
  • normalise — depth-scale counts during the merge. Default TRUE.
  • scale_factor — target sum per cell for depth scaling. Default 1e4.
  • log1p — apply log1p after scaling. Default TRUE.
  • normalise_by — "matrix" (joint matrix column sums, consistent with the DE offset) or "genome" (each cell’s total across all genes in its original object). Default "matrix".
  • layer_means_on — basis for the cell-type means driving layer assignment: "normalised" or "raw". Default "normalised".

$run()

Runs the full pipeline and writes to output_dir (matrix.mtx, matrix_normalised.mtx, metadata.txt, rowmetadata.csv, barcodes.tsv, features.tsv, normalisation.json).

merger <- CSHintMerger$new(
  orthofinder_resultdir = "filtered_proteomes/OrthoFinder/Results_Sep15/",
  scrna_dirs            = list(chicken = "filtered_scrna/chicken.h5ad",
                               human   = "filtered_scrna/human.h5ad"),
  output_dir            = "merged_output/",
  annotation_obs_col    = "cell_type",
  ncores                = 16
)

merger$run()

CSHintIntegration

Integrates species on the merged matrix: feature selection, PCA, then a thin-plate-spline warp across species.

All AnnData objects here are live Python references (reticulate proxies). Pass them straight back into subsequent calls rather than inspecting them as R objects.

integ <- CSHintIntegration$new(output_dir = "merged_output/")
  • output_dir — directory the merged matrices were written to by CSHintMerger.
  • reference_species — species ID to correct towards. NULL picks the species with the most cells during prepare_for_integration().

$load()

Re-loads matrix.mtx, metadata.txt and rowmetadata.csv from output_dir, then computes per-cell-type means.

$select_features(discriminability_threshold = 0.75, conservation_threshold = 0.5)

Selects features both conserved across species and discriminative between cell types. Conservation is scored first and filters the candidate pool; the discriminability cutoff is a percentile of the survivors only.

  • discriminability_threshold — percentile cutoff as a fraction (0.75 keeps the most variable quarter; 0.0 keeps all).
  • conservation_threshold — minimum mean pairwise Spearman correlation across species, in [-1, 1].

$to_anndata()

Converts the feature-by-cell matrix into a cell-by-feature AnnData, sliced to the selected features. Requires $select_features() first.

$prepare_for_integration(n_components = 50L)

Builds the AnnData and PCA embedding consumed by $integrate(). Normalises to 10,000 counts/cell, log1p, unit scaling clipped at 10 SD, then PCA. Also classifies cell types as a side effect.

  • n_components — principal components to compute. Must not exceed min(n_cells, n_features).

$integrate(adata_pca, ...)

Optimises n_anchors_target via Optuna, then refits and applies the correction with the winning parameters. Requires the scib Python package.

  • adata_pca — AnnData from $prepare_for_integration(), carrying obsm["X_pca"], obs["species"] and obs["cell_type"]. Modified in place.
  • n_trials — Optuna trials. Default 10.
  • n_jobs — trials run concurrently. Default 1.
  • random_state — seed for the TPE sampler, neighbour graph and Leiden. Default 42.
  • metric_weights — named list keyed by "ari", "nmi", "graph_connectivity", normalised to sum to one.
  • regularisation — ridge term on the TPS kernel diagonal. Default 1.0.
  • cell_type_agnostic — match anchors across the whole species pair rather than within shared cell types. Default FALSE.
  • min_anchor_weight — minimum rank correlation for a candidate pair to be kept. Default 0.3.
  • save — write the corrected AnnData to output_dir. Default TRUE.
  • prefix — filename stem used when save is TRUE. Default "integrated".

Returns a length-3 list: adata, study, best_params.

$integrate_no_optimization(adata, ...)

The fixed-parameter counterpart: anchor selection and TPS correction once, with no Optuna search.

  • nanchors — anchors per species pair. Default 1000.
  • X_ranked — precomputed rank-transformed embedding, or NULL.
  • chunk_size — row block size for the correlation matrix product. Default 512.
  • save, prefix — as for $integrate().

Other arguments as for $integrate(). Returns the corrected AnnData.

$post_integration_correction(adata, group_cols, ...)

Removes outlier cells per group using robust Mahalanobis distance (MCD) on PCA or UMAP coordinates. Only run if needed, after integration.

  • group_cols — .obs columns to group by, e.g. c("species", "cell_type").
  • method — "pca" uses obsm["X_pca"]; "umap" generates a UMAP first. Default "pca".
  • pval_cutoff — chi-squared threshold; cells below are removed. Default 0.01.
  • n_neighbors, min_dist, random_state — UMAP only.
  • save — write the filtered AnnData, replacing the file the integration step wrote. Default TRUE.
  • prefix — filename stem. Leave at the default to overwrite the integration output; change it to keep both versions.

$save_results(adata, prefix = "integrated", output_dir = NULL, overwrite = TRUE)

Writes an AnnData to output_dir. Called automatically by the three methods above; call it directly only to write an object again or under a different name.

integ$load()
integ$select_features(discriminability_threshold = 0.75,
                      conservation_threshold     = 0.5)

adata_pca <- integ$prepare_for_integration(n_components = 50)

# writes merged_output/integrated.h5ad
res <- integ$integrate(adata_pca, n_trials = 20)
res$best_params

# replaces merged_output/integrated.h5ad with the filtered version
integ$post_integration_correction(res$adata,
                                  group_cols = c("species", "cell_type"))

Because both steps default to prefix = "integrated", output_dir always holds the most corrected version. Pass a different prefix to the correction step to keep both.

Interoperability

seurat_to_h5ad()

Writes a Seurat object’s raw counts to h5ad for the Python side. The matrix is transposed on the way out: Seurat stores genes x cells, AnnData expects cells x genes.

  • sobj — a Seurat object.
  • path — output .h5ad path.
  • assay — assay to pull from. NULL uses the default assay.
  • layer — layer to pull. "counts" gives raw counts.
  • obs_columns — meta.data columns to keep. NULL keeps all storable columns.
  • overwrite — overwrite path if it exists. Default FALSE.

Returns path, invisibly.

seurat_to_h5ad(sobj, "human.h5ad", overwrite = TRUE)

Analysis

load.CSHintR.obj()

Loads a merged run into a single list used by everything below.

  • merged.dir — directory containing the merged output from the integration module.
  • orthofinder.dir — the OrthoFinder directory generated by CSHint.
  • integrated — file name of the integrated h5ad within merged.dir. Default "integrated.h5ad". Change this if you saved with a different prefix.
  • require.integrated — error when the integrated h5ad is missing. Default TRUE. FALSE loads the merged data alone, with a NULL embedding and no cell filtering.

Returns a list with matrix (normalised), rowmetadata, colmetadata, embedding, genetrees, orthogroups, and the two source directories.

obj <- load.CSHintR.obj(
  merged.dir      = "merged_output/",
  orthofinder.dir = "filtered_proteomes/OrthoFinder/Results_Sep15/"
)

Both paths are pasted directly onto filenames, so they need trailing slashes.

The integrated embedding is authoritative. Integration can drop cells — post_integration_correction() removes outliers — so metadata.txt is usually a superset of the integrated h5ad. The loader filters the count matrix and colmetadata down to the integrated cell set and puts every cell-indexed slot in the same order, so they are always row-comparable. A message reports how many cells were dropped.

subset_cells()

Filters every cell-indexed slot at once: matrix columns, colmetadata rows, and the embedding and umap coordinates where present. Gene-indexed slots are untouched.

  • CSHintR.obj — object from load.CSHintR.obj().
  • cells — logical vector, one element per row of colmetadata, TRUE to keep. A character vector of cell_ids also works.
obj_red <- subset_cells(obj, obj$colmetadata$cell_type == "Red")
obj_two <- subset_cells(obj, obj$colmetadata$species %in% c("human", "squirrel"))

The umap slot is carried through as-is, so points keep their original positions. To recompute the layout on just the retained cells, drop it first with obj$umap <- NULL and re-run run_umap().

cluster_genetree()

Dynamic tree cut of one orthogroup’s gene tree.

  • OG — orthogroup ID, e.g. "OG0009996".
  • CSHintR.obj — object from load.CSHintR.obj().
  • hclust.method — linkage passed to hclust(). Default "average".
  • cut.method, minClusterSize, deepSplit — passed to dynamicTreeCut::cutreeDynamic().

Returns a data frame with tip, cluster, species, gene. Trees with fewer than three tips are returned as a single cluster.

clusters <- cluster_genetree("OG0009996", obj)
head(clusters)

get_heatmap_dataframe()

Builds the long data frame the heatmap consumes.

  • OG — orthogroup ID of interest.
  • CSHintR.obj — object from load.CSHintR.obj().
  • ct — cell type(s) to keep. NULL keeps all.
  • ... — passed to cluster_genetree().

Returns a data frame with cell_id, species, celltype, count, gene, genecluster. Numeric-looking genecluster values came from the tree cut; the rest are orthogroup IDs for genes OrthoFinder placed outside this tree.

heatdf <- get_heatmap_dataframe("OG0009996", obj, ct = "Red")
head(heatdf)

Species with no gene in an orthogroup appear as species_NA. These are expected absences and are not warned about; genuinely unresolvable genes still are.

plot_cluster_heatmap()

Gene-by-cell heatmap stacked in one column, one row per gene cluster, with a dendrogram beside clusters that came from the tree and nothing beside those that did not. Species and cell type colour bars run along the bottom.

  • heatdf — data frame from get_heatmap_dataframe().
  • OG — orthogroup ID; the tree is pulled from CSHintR.obj$genetrees[[OG]].
  • CSHintR.obj — object from load.CSHintR.obj().
  • tree — optional tree overriding the lookup. Mostly for testing.
  • fill_colours — colours for the count scale, low to high. NULL uses viridis.
  • fill_option, fill_direction — viridis option and direction, used only when fill_colours is NULL. direction = 1 runs dark to light.
  • na_colour — colour for cell x gene combinations with no data.
  • species_colours — colours for the species bar, named by species or unnamed in alphabetical order.
  • species_palette — brewer palette, used when species_colours is NULL. Default "Set2".
  • celltype_colours — colours for the cell type bar, named by cell type or unnamed in alphabetical order.
  • celltype_palette — brewer palette, used when celltype_colours is NULL. Default "Dark2".
  • show_celltype — draw the cell type bar. Default TRUE.
  • cell_order — columns to sort cells by. Default c("species", "celltype", "cell_id").
  • tree_width — dendrogram column width relative to the heatmap.
  • bar_height — height of each annotation bar, in units of one gene row.
  • base_size — base font size.
  • panel_fill — background colour behind the tiles.

Returns a patchwork object.

plot_cluster_heatmap(heatdf, "OG0009996", obj)

# species bar only
plot_cluster_heatmap(heatdf, "OG0009996", obj, show_celltype = FALSE)

# custom colours
plot_cluster_heatmap(
  heatdf, "OG0009996", obj,
  fill_colours     = c("#0d0887", "#cc4778", "#f0f921"),
  species_colours  = c(human = "#4C72B0", chicken = "#C44E52"),
  celltype_colours = c(Red = "#C44E52", Blue = "#4C72B0")
)

Brewer palettes cap at 8–12 levels, so pass explicit colours for high-cardinality columns.

UMAP

run_umap()

Computes a UMAP from the integrated embedding and stores it on the object.

  • CSHintR.obj — object carrying $embedding (the TPS-corrected PCA).
  • n_neighbors, min_dist, metric — passed to uwot::umap().
  • seed — random seed for reproducible coordinates. NULL to skip.
  • ... — further arguments passed to uwot::umap().

Returns the object with a $umap data frame added (UMAP1, UMAP2).

obj <- run_umap(obj)
obj <- run_umap(obj, n_neighbors = 30, min_dist = 0.3)

plot_umap()

Scatter plot of the UMAP, coloured by any column of colmetadata.

  • CSHintR.obj — object with a $umap slot, from run_umap().
  • color — column of colmetadata to colour by. Default "cell_type".
  • cols — optional colours. Discrete columns take a named vector (names = levels) or an unnamed vector in sorted level order; numeric columns take a gradient to interpolate.
  • palette — brewer palette for discrete columns when cols is NULL.
  • point_size, alpha — point aesthetics.
  • label — for discrete columns, draw the level name at each group’s median position. Default FALSE.
  • base_size — base font size.

Returns a ggplot object. Numeric columns get a continuous scale automatically; everything else is treated as discrete.

plot_umap(obj, color = "cell_type")
plot_umap(obj, color = "species", cols = c(human = "#4C72B0", chicken = "#C44E52"))
plot_umap(obj, color = "cell_type", label = TRUE)
