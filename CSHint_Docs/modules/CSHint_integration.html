Cross-Species Integration

class CSHint_integration.CSHint_integration(output_dir, reference_species=None)[source]

Bases: object

This module manages species integration using the merged matrix output by the CSHint_merge module.

Steps:

  1. load() : Loads in the merged matrix

  2. select_features() : Selects a shortlist of features to use during integration

  3. prepare_for_integration(): Normalizes the data, runs PCA, and classifies cell types

  4. integrate() OR integrate_no_optimization() : Runs the TPS correction. integrate() is highly reccomended

  5. [ONLY IF NECESSARY] post_integration_correction() : removes cells that are not integrate properly

select_features(discriminability_threshold=0.75, conservation_threshold=0.5)[source]

Select features that are both conserved across species and discriminative between cell types.

Conservation is scored first and filters the candidate pool; the discriminability cutoff is then a percentile of the survivors only, so the two thresholds are not independent. Populates self.selected_features, self.discriminability_scores and self.conservation_scores.

Parameters:

  • discriminability_threshold (float) – Percentile cutoff on discriminability, expressed as a fraction and applied to the conservation-filtered candidates. This is a quantile, not a score: 0.75 keeps the most variable quarter of candidates, and 0.0 keeps all of them.

  • conservation_threshold (float) – Minimum mean pairwise Spearman correlation across species for a feature to be considered at all. Applied as an absolute score in [-1, 1], unlike the discriminability cutoff.

Returns:

None. Results are stored on the instance.

Return type:

None

Raises:

IndexError – If no feature clears conservation_threshold, leaving the percentile with an empty distribution.

prepare_for_integration(n_components=50)[source]

Build the AnnData object and PCA embedding consumed by optimize().

Runs total-count normalisation to 10,000 counts per cell, log1p, unit scaling clipped at 10 standard deviations, then PCA. Also classifies cell types, which populates self.pair_anchors as a side effect on the instance even though the returned object is not stored.

Parameters:

n_components (int) – Number of principal components to compute. Must not exceed min(n_cells, n_features).

Returns:

Preprocessed data with the embedding in obsm["X_pca"].

Return type:

anndata.AnnData

integrate(adata_pca, n_trials=10, n_jobs=1, random_state=42, metric_weights=None, regularisation=1.0, cell_type_agnostic=False, min_anchor_weight=0.3)[source]

Optimise n_anchors_target for TPS-based cross-species integration.

Anchor candidate correlations are computed once up front and shared read-only across trials; each trial then runs only the greedy match, the TPS warp and the scib metrics. Anchors pass between those stages by value, so trials stay independent when n_jobs > 1. Once the study completes, anchors are rebuilt with the winning parameters and the correction is applied to adata_pca in place, leaving self.anchors and self.best_params in agreement with it.

Scored metrics are ARI, NMI and graph connectivity;

Parameters:

  • adata_pca (anndata.AnnData) – Data carrying an uncorrected obsm["X_pca"] plus obs["species"] and obs["cell_type"]. Modified in place once the study has finished.

  • n_trials (int) – Number of Optuna trials to run.

  • n_jobs (int) – Number of trials to run concurrently.

  • random_state (int) – Seed for the TPE sampler, the neighbour graph and Leiden.

  • metric_weights (dict[str, float] or None) – Weights keyed by "ari", "nmi" and "graph_connectivity", normalised to sum to one. Defaults to {"ari": 0.4, "nmi": 0.2, "graph_connectivity": 0.4}.

  • regularisation (float) – Ridge term on the TPS kernel diagonal. Fixed across trials rather than optimised.

  • cell_type_agnostic (bool) – If True, match anchors across the whole species pair rather than within shared cell types.

  • min_anchor_weight (float) – Minimum rank correlation for a candidate pair to be retained during precomputation.

Returns:

The corrected anndata object, the completed study and its best parameter dictionary.

Return type:

tuple[adata, ptuna.study.Study, dict]

Raises:

ValueError – If _classify_cell_types() has not been run, or if fewer than two shared cell types exist across all species pairs.

integrate_no_optimization(adata, nanchors=1000, regularisation=1.0, X_ranked=None, cell_type_agnostic=False, chunk_size=512, min_anchor_weight=0.3)[source]

Run anchor selection and TPS correction once, without hyperparameter search.

The fixed-parameter counterpart to optimize(), for when the anchor count is already known. Stores the selected anchors on self.anchors and corrects adata in place.

Parameters:

  • adata (anndata.AnnData) – Data carrying an uncorrected obsm["X_pca"] plus obs["species"] and obs["cell_type"]. Modified in place.

  • nanchors (int) – Anchors to select per species pair.

  • regularisation (float) – Ridge term on the TPS kernel diagonal.

  • X_ranked (numpy.ndarray or None) – Precomputed rank-transformed embedding, or None to compute it.

  • cell_type_agnostic (bool) – If True, match across the whole species pair rather than within shared cell types.

  • chunk_size (int) – Row block size for the correlation matrix product.

  • min_anchor_weight (float) – Minimum rank correlation for a pair to be retained.

Returns:

The corrected data.

Return type:

anndata.AnnData

post_integration_correction(adata, group_cols, method='pca', pval_cutoff=0.01, n_neighbors=15, min_dist=0.1, random_state=42)[source]

Remove outlier cells per group using robust Mahalanobis distance (MCD estimator) on either PCA or UMAP coordinates.

Parameters:

  • adata (AnnData object output from CSHint_integration)

  • group_cols (list of .obs columns to group by e.g. ["species", "ct"])

  • method ("pca" uses .obsm["X_pca"]; "umap" generates a UMAP first) – then uses .obsm[“X_umap”]

  • pval_cutoff (chi-squared p-value threshold; cells below this are removed)

  • n_neighbors ((umap only) number of neighbours for sc.pp.neighbors)

  • min_dist ((umap only) min_dist passed to sc.tl.umap)

  • random_state ((umap only) random seed for reproducibility)

Return type:

AnnData with outlier cells removed, plus adata.obs[“_outlier”] bool column
