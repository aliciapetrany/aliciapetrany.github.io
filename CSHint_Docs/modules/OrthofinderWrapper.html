OrthoFinder wrapper

class OrthofinderWrapper.OrthoFinderWrapper[source]

Bases: object

Thin wrapper around OrthoFinder and its inputs and outputs.

run_orthofinder(inputdir, orthofinder_path, threads=16)[source]

Run OrthoFinder over a directory of proteome FASTA files.

Invokes the OrthoFinder executable as a shell command and blocks until it finishes. Results are written to OrthoFinder’s own output directory beneath inputdir, not returned; pass that path to read_orthogroups() afterwards.

Parameters:

  • inputdir (str) – Directory of proteome FASTA files to compare.

  • orthofinder_path (str) – Path to the OrthoFinder executable.

  • threads (int) – Threads for OrthoFinder to use. Also updates self.threads.

Returns:

None. Output is written to disk.

Return type:

None
