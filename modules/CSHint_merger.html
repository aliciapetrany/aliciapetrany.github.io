Count Merging

class CSHint_merger.CSHint_merger(orthofinder_resultdir, scrna_dirs, output_dir, annotation_obs_col, ncores=16, counts_layer=None, normalise=True, scale_factor=10000.0, log1p=True, normalise_by='matrix', layer_means_on='normalised')[source]

Merge per-species scRNA-seq into a joint orthogroup-layer matrix.

Writes BOTH matrix.mtx (raw integer counts) and matrix_normalised.mtx (depth-scaled, optionally log1p).

__init__(orthofinder_resultdir, scrna_dirs, output_dir, annotation_obs_col, ncores=16, counts_layer=None, normalise=True, scale_factor=10000.0, log1p=True, normalise_by='matrix', layer_means_on='normalised')[source]

Initialise a cross-species merge run.

Validates the enumerated options and sets up the empty containers that load() and the merge steps populate.

Parameters:

  • orthofinder_resultdir (str) – Directory holding the OrthoFinder results used for orthogroup assignment.

  • scrna_dirs (dict[str, str]) – Input scRNA-seq paths keyed by species. The keys define the species set for the run.

  • output_dir (str) – Destination for the merged matrix and its metadata.

  • annotation_obs_col (str) – Column in adata.obs holding the cell type labels.

  • ncores (int) – Worker processes for the parallelised steps.

  • counts_layer (str or None) – Layer holding raw counts, e.g. "counts". None uses adata.X. Set this whenever adata.X has been normalised in place — otherwise matrix.mtx will contain normalised values under a raw name, and every downstream integer check will pass while the NB offset double-corrects for depth.

  • normalise (bool) – Whether to depth-scale counts during the merge.

  • scale_factor (float) – Target sum per cell for depth scaling.

  • log1p (bool) – Whether to apply log1p after scaling.

  • normalise_by (str) – Denominator for depth scaling. "matrix" uses the joint matrix column sums, which is what the DE offset uses, so the two stay consistent. "genome" uses each cell’s total across all genes in its original object, which is the true library size but includes genes dropped during orthogroup assignment.

  • layer_means_on (str) – Basis for the cell-type mean profiles that drive layer assignment, either "normalised" or "raw".

Raises:

ValueError – If normalise_by or layer_means_on is not one of its permitted values.

run()[source]

Execute the full merge pipeline end to end.

Loads the OrthoFinder orthogroups and per-species expression data, computes anchor cell-type mean profiles, assigns genes to layers by greedy expression similarity, fills the joint matrix, optionally normalises it, and writes the result to self.output_dir.

Normalisation runs only when self.normalise is set; the parameters governing each step are those fixed at construction.

Returns:

None. Output is written to disk and to the instance attributes populated along the way.

Return type:

None
