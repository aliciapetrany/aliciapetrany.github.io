Preprocessing

class CSHint_preprocess.CSHint_preprocess[source]

Bases: object

Preprocessing utilities for CSHint_merger inputs.

Steps (all optional, call what you need before merger.run()):

  1. preprocess_fasta_headers() : rename NCBI protein FASTA headers to gene symbols

  2. synchronize_scrna_and_proteomes() : prefilter cells/genes before merging

preprocess_fasta_headers(gtf_fasta_map, out_dir=None)[source]

Rename FASTA headers from raw accessions to gene symbols.

Detects RefSeq versus Ensembl annotation format independently for each species, including whether the annotation is GTF or GFF3, then builds an accession-to-gene index and rewrites the headers against it. For each species this writes a renamed {species}.faa alongside a {species}_id_map.csv recording the mapping that was applied.

Parameters:

  • gtf_fasta_map (dict[str, dict[str, str]]) – Input paths per species, as {"species": {"gtf": "path/to/file.gtf|.gff", "fasta": "path/to/file.faa"}, ...}.

  • out_dir (str or None) – Destination for the renamed FASTAs and ID maps. Created if absent. Defaults to self.output_dir.

Returns:

None. Output is written to disk.

Return type:

None

synchronize_scrna_and_proteomes(species_map, prot_out_dir=None, scrna_out_dir=None)[source]

Filter scRNA-seq and protein sequences to the genes shared between them.

FASTA headers are assumed to already be gene symbols. Both gene names and record IDs are upper-cased before intersecting, so the two sources need only agree up to case. Each species is written out as a filtered .h5ad and .faa pair named after the species key; species with no shared genes are skipped with a warning rather than raising.

Note that duplicate gene symbols created by upper-casing are disambiguated with a - suffix, which will not match any FASTA record and so drops those genes from the intersection.

Parameters:

  • species_map (dict[str, dict[str, str]]) – Input paths per species, as {"species_name": {"h5ad": "path.h5ad", "fasta": "path.faa"}, ...}.

  • prot_out_dir (str) – Directory for the filtered proteomes. Created if absent.

  • scrna_out_dir (str) – Directory for the filtered expression data. Created if absent.

Returns:

None. Output is written to disk.

Return type:

None

Raises:

TypeError – If either output directory is left as None.
